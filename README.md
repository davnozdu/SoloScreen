# SoloScreen

Бесплатная утилита для macOS: при подключении AR-очков гасит встроенный экран
MacBook и оставляет изображение только на очках, а когда очки отключаются —
возвращает встроенный экран обратно.

Заменяет одну конкретную функцию платного BetterDisplay, без всего остального.

## Возможности

- Автоматическое выключение встроенного экрана при подключении **выбранных**
  устройств. Проектор или обычный монитор ничего не запускают — реагируют
  только те экраны, которые вы отметили сами.
- Возврат встроенного экрана при отключении очков.
- Ручное переключение встроенного экрана тумблером в настройках или горячей
  клавишей, не отключая очки.
- Горячая клавиша назначается самостоятельно: сочетание набирается прямо в окне
  настроек. По умолчанию ⌃⌥⌘D.
- Закрепление режима экрана: разрешение и **частота обновления** выставляются
  автоматически при каждом подключении устройства.
- Регулировка яркости внешнего экрана из меню в строке меню.
- Подсказка при первом подключении незнакомого экрана.
- Иконка в строке меню и иконка в Dock.
- Автозапуск при входе в систему.
- Автообновление.

## Требования

- Apple Silicon (M1 и новее)
- macOS 14 или новее

## Установка

1. Скачайте DMG со страницы [релизов](../../releases) и перетащите SoloScreen
   в «Программы».
2. При первом запуске macOS предупредит о неизвестном разработчике: щёлкните по
   приложению правой кнопкой и выберите «Открыть». Приложение подписано
   собственным сертификатом, без платного Apple Developer ID, поэтому обход
   нужен ровно один раз.
3. Подключите очки, откройте меню в строке меню и отметьте их в списке
   «Гасить ноутбук для устройства».

## Управление

Ручное переключение доступно тремя способами, и все они управляют одним
состоянием:

- **Тумблер «Выводить только на внешний экран»** — первым в окне настроек,
  виден всегда. Гасит и возвращает встроенный экран прямо сейчас, без
  перетыкания кабеля.
- **Пункт «Только внешний экран»** в меню строки меню — с галочкой, по которой
  видно текущее состояние, и с назначенным сочетанием справа.
- **Горячая клавиша.**

Отдельно, в карточке каждого внешнего экрана, живёт галочка **«Гасить
встроенный автоматически при подключении»** — она про автоматику, а не про
ручное управление, и заносит устройство в белый список.

Горячая клавиша назначается в настройках: нажмите поле с сочетанием и наберите
нужное, Esc отменяет запись. Годится любое сочетание из модификаторов
(⌃ ⌥ ⇧ ⌘) и обычной клавиши — на голый модификатор действие повесить нельзя,
это ограничение механизма, который позволяет обойтись без разрешения
«Универсальный доступ».

## Режим экрана

macOS для AR-очков нередко выбирает 60 Гц, хотя устройство умеет больше, а
высокие частоты прячет из системных настроек. XREAL One Pro, например,
поддерживает 1920×1080 при 120 Гц, но по умолчанию подключается на 60.

В карточке экрана выбирается разрешение и частота; выбор привязан к устройству
и применяется при каждом подключении. Вариант «Как решит система» оставляет всё
на усмотрение macOS.

Приложение запрашивает у системы и те режимы, которые скрыты от «Настроек» —
именно там у очков лежат высокие частоты. Подстановка похожего режима вместо
запрошенного не делается: молча оказаться не на той частоте хуже, чем остаться
на прежней.

## Как это работает

Встроенный экран выключается через `SLSConfigureDisplayEnabled` из SkyLight
(с откатом на `CGSConfigureDisplayEnabled`). Права администратора и отключение
SIP не требуются. Экран полностью исчезает из «Настроек → Мониторы», а не просто
гаснет.

Устройства запоминаются по EDID (`vendor`, `model`, `serial`), а не по
идентификатору дисплея: последний меняется при каждом переподключении.

Горячая клавиша регистрируется через Carbon `RegisterEventHotKey`, а её запись в
настройках — через локальный монитор событий, который ловит клавиши только при
активном окне приложения. Ни то, ни другое не требует разрешения «Универсальный
доступ».

Яркость внешнего экрана регулируется гамма-таблицей. Аппаратный путь (DDC/CI) у
AR-очков отсутствует.

### Виртуальная заглушка macOS

Когда гаснут все физические экраны, система подставляет виртуальный дисплей
(`vendor` = «unkn», `model` = «virt», без имени). Приложение его распознаёт и не
считает внешним экраном — иначе выключенный вручную встроенный экран так и не
вернулся бы после отключения очков: политика видела бы заглушку и решала, что
выводить есть куда.

### Сон и пробуждение

После сна панель AR-очков может не ожить, хотя macOS показывает дисплей
активным и отдаёт его режим. Отличить «экран есть» от «экран чёрный»
программно в такой ситуации нельзя, поэтому защита сделана поведением:

- перед сном встроенный экран включается обратно;
- после пробуждения он остаётся включённым, а автоматика для переживших сон
  экранов не срабатывает, пока их не переподключат или вы не переключите
  режим сами.

Если удобнее, чтобы вывод на внешний экран восстанавливался сам, включите в
настройках «После пробуждения возвращаться в режим внешнего экрана» и задайте
задержку (по умолчанию 5 секунд) — за это время видно, ожили очки или нет, и
можно успеть вернуть экран ноутбука горячей клавишей.

### Чтобы не остаться без изображения

Выключенный встроенный экран при сбое означал бы Mac без картинки, поэтому
восстановление подстраховано четырьмя независимыми рубежами:

1. Реакция на изменение конфигурации экранов плюс собственный опрос раз в две
   секунды — системные уведомления об отключении экрана приходят не всегда.
2. Восстановление при завершении приложения, включая сигналы `SIGTERM`
   и `SIGINT`.
3. Проверка при запуске: если встроенный экран выключен, а доверенных внешних
   нет — он включается сразу.
4. Изменение применяется в режиме «на сессию», поэтому перезагрузка в любом
   случае возвращает экран.

Ручное выключение встроенного экрана привязано к тому внешнему, ради которого
оно сделано: как только этот экран отключают, режим снимается сам.

Второй экземпляр приложения не запускается — две копии вели бы каждая свой
опрос и спорили бы за состояние экрана.

### Что приложение не делает

- **Не трогает звук.** В нём нет зависимостей от CoreAudio и AudioToolbox, что
  проверяется отдельным шагом CI. Переключение звука на очки остаётся штатным
  поведением macOS, а выбранные вручную наушники никто не перебьёт.
- **Не трогает яркость встроенного экрана.** Автоподстройка сама корректно
  переживает выключение экрана, а вмешательство её бы сломало.

## Сборка из исходников

```sh
swift test
VERSION=0.1.0 ./Scripts/build-app.sh
VERSION=0.1.0 ./Scripts/make-dmg.sh
```

Готовые DMG собираются на GitHub Actions при публикации тега `v*`.

### Секреты репозитория

| Секрет | Назначение |
| --- | --- |
| `SIGNING_CERTIFICATE_P12` | самоподписанный сертификат в base64 |
| `SIGNING_CERTIFICATE_PASSWORD` | пароль к нему |
| `SPARKLE_PRIVATE_KEY` | приватный EdDSA-ключ для подписи обновлений |

Подпись должна оставаться неизменной между версиями, иначе Sparkle откажется
устанавливать обновление поверх установленной копии.
