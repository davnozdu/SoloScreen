# SoloScreen — спецификация

Дата: 2026-09-07
Статус: утверждено пользователем

## Задача

Бесплатная замена BetterDisplay для одного сценария: при подключении AR-очков
(Xreal Air) гасить встроенный экран MacBook, выводить картинку только на очки,
а при отключении очков возвращать встроенный экран. Плюс ручная регулировка
яркости внешнего экрана.

## Целевая среда

- MacBook Pro 16" (Mac14,10), Apple M2 Pro, arm64 — **только Apple Silicon**
- macOS 26.6.2 (Tahoe); минимальная поддерживаемая — macOS 14
- Xreal Air как внешний дисплей 1920x1080, без DDC/CI

## Результаты спайка (проверено на железе 2026-09-07)

| Проверка | Результат |
| --- | --- |
| `SLSConfigureDisplayEnabled` (SkyLight) | резолвится, отключает и возвращает внешний дисплей, `CGError = 0` |
| То же для встроенного дисплея | работает, картинка уходит на внешний |
| Права root / отключение SIP | не требуются |
| DDC/CI на внешнем дисплее | `DisplayServicesCanChangeBrightness = false` — аппаратной яркости нет |
| `CGSetDisplayTransferByFormula` (гамма) | работает, подтверждено визуально |
| Яркость встроенного после цикла выкл/вкл | сохраняется, автоподстройка остаётся включённой |

Отвергнутый путь: `SLSDisplayPowerControlClient` (эмуляция clamshell) — требует
отключения SIP и `amfi_get_out_of_my_way=1`.

## Архитектура

Модули с одной ответственностью, логика отделена от приватных API, чтобы
тестировать её без железа.

### DisplayKit
Обёртка над системными API. Единственный модуль, знающий про приватные символы.
- перечисление через `CGGetOnlineDisplayList`
- включение/выключение через `SLSConfigureDisplayEnabled` с откатом на
  `CGSConfigureDisplayEnabled`, внутри `CGBeginDisplayConfiguration` /
  `CGCompleteDisplayConfiguration`
- режим завершения — **`.forSession`**, намеренно: изменение не переживает
  перезагрузку, поэтому отказ приложения лечится ребутом

### DisplayIdentity
Идентификация экрана по EDID (`vendor`, `model`, `serial`), а не по
`CGDirectDisplayID`: последний меняется между переподключениями и как ключ
белого списка не годится.

### TrustedDevices
Белый список устройств, для которых гасится встроенный экран. Хранение в
`UserDefaults`. Проектор и обычные мониторы в список не входят и ничего не
запускают.

### BrightnessController
Гамма через `CGSetDisplayTransferByFormula`.
- при каждом подключении внешнего экрана — 100% (гамма 1.0)
- слайдер понижает до 10%
- значение **не запоминается** между подключениями
- при отключении экрана и при выходе из приложения гамма сбрасывается

### DisplayCoordinator
Машина состояний и реакция на `CGDisplayRegisterReconfigurationCallback`.

### SafetyGuard — четыре рубежа восстановления экрана
Опасный сценарий: встроенный выключен, очки отключены, приложение упало.
1. реакция на reconfiguration — исчез доверенный внешний, встроенный включается
2. восстановление в `applicationWillTerminate` и обработчиках `SIGTERM`/`SIGINT`
3. проверка на старте: встроенный выключен и доверенного внешнего нет → включить
4. `.forSession` — перезагрузка всегда возвращает экран

### Интерфейс
- иконка в строке меню (`NSStatusItem`): состояние, слайдер яркости,
  переключение встроенного экрана, доверенные устройства, настройки, выход
- иконка в Dock (`LSUIElement = NO`), клик открывает минимальное окно настроек
  на SwiftUI: список экранов с галочкой «доверенное», горячая клавиша,
  автозапуск, проверка обновлений
- горячая клавиша ⌃⌥⌘D через Carbon `RegisterEventHotKey` — **не требует
  разрешения Универсального доступа**, в отличие от `CGEventTap`; переключает
  встроенный экран, не трогая очки
- автозапуск через `SMAppService.mainApp` (macOS 13+)

## Инварианты

1. **Аудио не трогаем.** Приложение не имеет зависимостей от CoreAudio и
   AudioToolbox. Переключение звука на очки остаётся штатным поведением macOS,
   ручной выбор наушников не перебивается. Проверяется тестом на линковку.
2. **Яркость встроенного экрана не трогаем.** `DisplayServicesSetBrightness` для
   встроенного не вызывается никогда — иначе сломается автоподстройка.

## Сборка и поставка

- Swift Package Manager, `.app` собирается скриптом (без зависимости от Xcode)
- GitHub Actions на `macos-15`, артефакт — **DMG, только arm64**
- **Постоянная подпись**: самоподписанный сертификат создаётся один раз, `.p12`
  в GitHub Secrets, им подписывается каждый релиз — identity не меняется между
  версиями, поэтому Sparkle принимает обновления
- Автообновление через Sparkle 2, постоянный EdDSA-ключ, публичная половина в
  `Info.plist`, `appcast.xml` в GitHub Releases
- Платного Developer ID нет, поэтому первая установка требует разового обхода
  Gatekeeper (ПКМ → «Открыть»); последующие обновления идут автоматически

## Вне области первой версии

Перехват F1/F2 для яркости очков (требует Универсального доступа), управление
разрешениями и расположением экранов, поддержка Intel, оверлей-затемнение как
запасной механизм яркости.

## Тестирование

Unit-тесты без железа: сопоставление EDID с белым списком, машина состояний,
правила восстановления, проверка отсутствия линковки CoreAudio. Обёртки над
приватными API проверяются интеграционно на живом железе.
